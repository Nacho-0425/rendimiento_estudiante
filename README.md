# Análisis de Rendimiento Estudiantil (Students Performance)

Este proyecto realiza un análisis exploratorio y preprocesamiento de datos sobre el rendimiento académico de estudiantes utilizando un dataset de Kaggle.

## Requisitos de Entorno
- Python 3.x
- Librerías: `pandas`, `numpy`, `matplotlib`

## Estructura del Proyecto
- `StudentsPerformance.csv`: Dataset original de Kaggle.
- `main.py`: Script de Python con el análisis exploratorio y cálculo de promedios.
- `requirements.txt`: Dependencias del entorno virtual.
